● I can see the issue. The lines pad the labels with spaces hoping to align the
  colons, but Noto Sans is proportional, so that doesn't work — and each line is
   then centered individually, making the colons drift to different x-positions.

  The fix: split each row into (label, value) and lay them out as a block —
  labels right-aligned to a shared colon column, values left-aligned past it.
  Then center the whole block.

     Editor overhaul: Hierarchy → Inspector → tools → grid styling

     Context

     The current Hierarchy panel (GameLayer::DrawHierarchyPanel in
     src/layers/imgui_layer.cpp's sibling game_layer.cpp) only shows
     SceneManager debug. The Inspector (src/scenes/editor_panels.cpp) is keyed
     off a cursor and is read-only. The viewport just clears with
     theme::kBackground — no grid, no styling.

     The user wants this to evolve into a real in-engine level editor, mirroring
      what they built in ../baba:

     1. Hierarchy grouped by region, listing the only dynamic entities — Player
     and crates (Pushable).
     2. Inspector keyed off Hierarchy selection (selection-priority), with Cell
     editable as integers.
     3. Tool palette like baba: Brush / Line / RectOutline / RectFilled / Bucket
      / Eraser. Drag to draw, flood-fill, etc.
     4. Grid background + overlay with theme-able colors, opacity, thickness,
     show/hide — same DSL as baba.

     Crate ≡ Pushable. Wall / floor / decoration are static and don't need to
     appear in Hierarchy.

     This plan executes the work as three commits so each is independently
     shippable and reviewable. Phase 1 unblocks the architectural question
     (where Hierarchy lives) before larger pieces land on top.

     Architecture decision

     Scene owns the editor surface. GameplayScene already owns the World,
     editor::State, and the existing editor panels. The new Hierarchy is just
     another editor::Draw* function in scenes/editor_panels.cpp. GameLayer's
     empty placeholder Hierarchy panel + the View-menu wiring for it gets
     removed — the dock builder still slots a window named Hierarchy into
     dock_left, only now the scene populates it. No cross-layer plumbing.
